# Copilot skill files for Hub Mobile

This folder contains prompt templates and instructions to help Copilot or assistant produce better, project-aligned code for the Hub Mobile Flutter app.

Files:
- `SKILL.md` — skill manifest and metadata.
- `project.instructions.md` — coding conventions and local verification commands.
- `project.prompt.md` — reusable prompt templates for common tasks.

How to use:
- When asking Copilot/assistant for code changes, start from the templates in `project.prompt.md` and include relevant file paths and error logs.
- Follow `project.instructions.md` to ensure code style, tests, and verification steps are maintained.
